# pry — vendored pool-tag -> driver mapping
#
# Format mirrors Microsoft's WDK `pooltag.txt` artifact (one entry per line):
#     TAG - OWNER - DESCRIPTION
# where OWNER is `<driver>!<component>` or just `<driver>`. Lines starting
# with `#`, blank lines, and the Microsoft-style `rem` prefix are ignored
# so a WDK scrape can be dropped in verbatim.
#
# Scope: canonical kernel-mode allocation tags from public WDK /
# Windows-Internals / debugger documentation. SI's `triage/pooltag.txt`
# is NOT vendored — see `an internal plan
# 04-umagent-orchestrator.md#feature-4` for the licensing note; this
# file is seeded from public reference material (WDK symbol strings,
# `!poolused` samples). Grow it via `scripts/build_pooltag_from_wdk.py`
# as that scrape lands.
#
# -----------------------------------------------------------------------
